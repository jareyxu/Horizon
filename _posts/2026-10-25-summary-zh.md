<div class="archive-item-heading"><h3><a href="https://github.com/anthropics/claude-code/releases/tag/v2.1.310">anthropics/claude-code 发布 v2.1.310 版本</a></h3><span class="score-badge" data-tier="low">1.7</span></div>
<p class="archive-original-title">anthropics/claude-code released v2.1.310</p><p class="source-line">ashwin-ant · 10-23 23:39 UTC</p>
<p class="archive-item-content">Claude Code 在 GitHub 上发布了 v2.1.310 版本更新。</p>
<p class="archive-assessment">AI 判断：标题初筛（未依据正文）：这是面向开发者的命令行工具版本更新，普通用户难以实际使用，仅凭标题也看不到可演示的效果，按技术类低分处理。</p>
<details class="archive-original"><summary>展开原始摘录</summary><p>## What&#x27;s changed<br><br>- Added the Monitor tool and plugin monitors on Bedrock, Vertex, and Foundry, and when telemetry or nonessential traffic is disabled; long foreground sleeps are now blocked there too<br>- Fixed requests failing behind some gateways and compatible servers that reject the `effort-2025-11-24` beta value or mid-conversation system messages; Claude Code now retries without them<br>- Fixed background cleanup deleting some recent files, such as pasted images, when `cleanupPeriodDays` is set to a very large value<br>- Fixed compaction after a &quot;Prompt is too long&quot; error keeping too much of a conversation with dense text, such as base64 or SVG, so the next request could fail again<br>- Fixed file read permission prompts not showing where a symbolic link leads<br>- Fixed a question&#x27;s auto-continue timeout firing the moment the external editor closed after a long edit<br>- Windows: Fixed PreToolUse and PermissionRequest hooks letting a tool call through when Git Bash is missing and the hook&#x27;s command is only quoted strings, such as a quoted path<br>- Improved auto mode&#x27;s prompt before the first read outside the working directories: it now says when blocking those reads makes shell commands ask for permission<br>- Improved memory use of non-interactive sessions (`-p`, Agent SDK) during compaction when the transcript file is very large<br>- Improved a mod&#x27;s `Image` to draw inside tmux with `allow-passthrough` and `focus-events` on, in kitty, Ghostty, and iTerm2 3.5+ with fullscreen rendering, where it showed only its `alt` text<br>- Linux: Improved `/sandbox` and the sandbox startup warning to name Ubuntu&#x27;s AppArmor restriction on user namespaces, and how to lift it, when it keeps bubblewrap from starting the sandbox<br>- Changed the error for an MCP tool call that times out in a non-interactive session while the server&#x27;s elicitation is unanswered: it now tells Claude that no answer came and not to repeat the call<br>- [VSCode] Fixed pressing Enter on the plan review card&#x27;s &quot;Send feedback and keep planning&quot; button approving the plan instead of sending your comments back<br>- [VSCode] Fixed the panel showing &quot;Something went wrong&quot; after &quot;Switch branch &amp; continue&quot; on a cloud session opened from Session history&#x27;s Web tab<br>- [Cloud sessions] Added Claude Code cloud sessions and Remote Control permissions to Enterprise custom roles, so Owners can control access to each by role<br>- [Cloud sessions] Added a Choose file button to load a cloud environment&#x27;s setup script from a file<br>- [Cloud sessions] Fixed failed saves and archives in the cloud environment edit dialog showing no error inside the dialog<br>- [Cloud sessions] Fixed failed routine API token actions showing only a toast; the error now appears in the routine edit dialog<br>- [Cloud sessions] Improved the session start checklist to show a cloud environment&#x27;s setup script output in a scrolling box<br>- [Cloud sessions] Changed turning on Cloud sessions or Remote Control in admin settings to ask for confirmation and list the custom roles that have that permission<br>- [Cloud sessions] Changed the cloud environment dialog to open network access, setup script and environment variables from rows instead of listing every editor at once<br>- [Claude Tag] Fixed Claude Tag treating `!` commands such as `!restart` and `!help` as ordinary messages when sent in bold, italic or strikethrough<br>- [Claude Tag] Fixed Claude Tag admin channel and workspace pages being replaced by a load error when a background refresh of the bundle list fails<br>- [Claude Tag] Fixed Claude Tag&#x27;s spend limits page in admin settings reporting that no channels match a filter while channel names are still loading<br>- [Code Review] Fixed the Code Review admin section hiding its repositories and switches after a failed refresh of the repository list<br>- [Code Review] Improved the Code Review admin section to retry the first load and show one Try again banner when it still fails</p></details>
